# Skypro.Wallet — React + localStorage

Одностраничное приложение на React по макету Figma **Skypro.Wallet (Copy)**. Данные пользователей и расходов хранятся в `localStorage` — сервер и база данных не требуются.

## Структура проекта

```
frontend/
  index.html              # точка входа, шрифт Montserrat, favicon, meta
  vite.config.js          # Vite + @vitejs/plugin-react, dev-порт 5173
  public/
    favicon.svg           # иконка вкладки
    assets/logo.png       # логотип из макета (288×38 → 19px по высоте)
  src/
    main.jsx              # ReactDOM + ErrorBoundary
    App.jsx               # маршруты приложения и защита приватных экранов
    ErrorBoundary.jsx     # перехват ошибок рендера
    index.css             # токены макета + все стили экранов
    components/
      Header.jsx          # шапка: логотип, навигация (NavLink), выход
      Logo.jsx            # логотип-ссылка на /expenses
      InputField.jsx      # поле с меткой, состоянием ошибки и подсказкой
      PrimaryButton.jsx   # основная кнопка
      LinkText.jsx        # текстовая ссылка на другой экран
    constants/categories.js  # категории: подпись, эмодзи, цвет (единый источник)
    context/AuthContext.jsx  # авторизация + RequireAuth (защита маршрутов)
    data/sampleExpenses.js   # демо-расходы нового пользователя
    pages/
      Login.jsx, Register.jsx, Expenses.jsx, Analytics.jsx, NotFound.jsx
    services/storage.js   # работа с localStorage (пользователи, расходы, сессия)
    utils/date.js         # даты: ISO, ДД.ММ.ГГГГ, «10 июля 2024», месяцы периода, сетка календаря
    utils/format.js       # суммы в формате «3 590 ₽»
```

## Маршруты

| Путь         | Экран               | Доступ                |
| ------------ | ------------------- | --------------------- |
| `/login`     | Вход                | всем                  |
| `/register`  | Регистрация         | всем                  |
| `/expenses`  | Мои расходы         | только авторизованным |
| `/analytics` | Анализ расходов     | только авторизованным |
| `*`          | Страница не найдена | всем                  |

`/expenses` и `/analytics` защищены `RequireAuth`: неавторизованного пользователя редиректит на `/login`, после входа он возвращается на запрошенный экран. Панель навигации скрыта на экранах входа, регистрации и 404 (как в макете).

## Экраны

- **Вход** — email (или имя) + пароль, ошибки валидации по макету.
- **Регистрация** — имя, email, пароль (≥ 6 символов).
- **Мои расходы** — таблица расходов с удалением и форма добавления: описание, категория, дата, сумма. Дата не может быть позже сегодняшней.
- **Анализ расходов** — календарь с выбором дня и бар-чарт по категориям за выбранный день. Периоды не зашиты в макет: список месяцев идёт от месяца первого расхода до **текущего** месяца, будущие дни недоступны (`disabled`), сегодняшний день обведён. По умолчанию выбран день последнего расхода; при открытии календарь прокручивается к выбранному месяцу.

## Данные и хранилище

Ключи `localStorage`:

| Ключ                     | Содержимое                                                          |
| ------------------------ | ------------------------------------------------------------------- |
| `wallet_users`           | массив пользователей (`id`, `name`, `email`, `password`)            |
| `wallet_current_user`    | текущая сессия (`id`, `name`, `email`)                              |
| `wallet_expenses`        | все расходы (`id`, `userId`, `title`, `category`, `date`, `amount`) |
| `wallet_seeded_<userId>` | флаг «демо-данные уже добавлены»                                    |

- Новому пользователю один раз подставляются демо-расходы из `data/sampleExpenses.js`.
- Расходы выдаются по `userId` и сортируются по дате (свежие сверху).
- Удалить расход может только его владелец.
- Сброс данных — очистка `localStorage` в DevTools.

## Ошибки ввода (по макету)

- Ошибочное поле получает светло-красный фон `#ffeaea` и обводку `#f24f4f`, у метки появляется `*`.
- Под формой выводится общий текст ошибки.
- Кнопка отправки блокируется только на время запроса и разблокируется после ответа.

## Производительность

- Маршруты и данные читаются один раз за рендер: списки, суммы и календарь считаются в `useMemo`.
- Сторонних UI-библиотек и иконочных шрифтов нет: логотип — PNG из макета, favicon — SVG.
- Сборка Vite: один JS-чанк (~72 КБ gzip), CSS ~2 КБ gzip.
